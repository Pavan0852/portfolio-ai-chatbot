# RecoMart — Movie Recommendation Engine

## Overview
RecoMart is a personal movie recommendation project using movie ratings and metadata to explore personalised recommendations.

## Data
- MovieLens ratings data
- TMDB metadata where integrated

## Approach and technology
- Python-based data ingestion and processing
- Collaborative filtering
- Movie metadata integration
- An earlier prototype interface built with Streamlit

## Goals
- Process user-movie rating data.
- Learn preference patterns from historical ratings.
- Generate personalised movie recommendations.
- Use metadata to make recommendations more informative.

Do not claim specific recommendation accuracy, ranking metrics, user counts, or production deployment unless measured and documented. Streamlit was used in an earlier prototype; the current portfolio UI preference is Next.js.
